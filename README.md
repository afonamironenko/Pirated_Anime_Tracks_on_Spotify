# Pirated_Anime_Tracks_on_Spotify
Goal of the analysis: to estimate how many streams and how much revenue “pirate” anime content earns on Spotify, using my own anime remixes as a case study, and to use this to reason about how wide the market is.

# What this project does
1) Analyzes 5-3 years spotify data.
2) Discusing about this topic.
3) Estimates conclusions.

## Structure
1) `data/` — spotify data (.csv)
2) `scripts/public.R` — R script for data cleaning, analysis, and visualization
3) `plots/` — generated charts (.png)
